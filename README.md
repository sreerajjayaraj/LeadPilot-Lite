# LeadPilot Lite

LeadPilot Lite is a mobile-first lead follow-up assistant for small businesses. It is built as a static Progressive Web App, so it can be hosted on GitHub Pages with no backend, no database, and no monthly infrastructure cost.

## What it does

- Stores leads locally on the user device
- Ranks follow-up urgency with a local scoring engine
- Generates ready-to-copy follow-up messages
- Tracks lead stage, value, temperature, source, notes, and last contact date
- Exports leads as CSV
- Installs on mobile as a PWA from the browser
- Works offline after first load

## Why this fits a no-upkeep product

There is no server to maintain. Buyer data stays in their browser local storage. The "AI-style" assistant is deterministic and local, so you do not need to pay for API usage or manage user accounts.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. In GitHub, open `Settings`.
4. Open `Pages`.
5. Under `Build and deployment`, choose `Deploy from a branch`.
6. Choose the `main` branch and `/root`.
7. Save.

GitHub will give you a public URL. That URL is the app.

## Preview locally

If Node.js is installed, run:

```bash
node dev-server.js
```

Then open `http://127.0.0.1:4173`.

## Important limitation

Because this version has no backend, leads are stored on one device/browser. That is what keeps it maintenance-free. A future premium version could add sync, team accounts, WhatsApp integration, or real AI message generation.
